# 画出原创乐曲（Draw Your Song）

**轻松创作乐曲，并配上著作权申报文件。**

**不需要识谱，不需要会乐器，不需要安装任何东西。** 打开网页就能用。

## 它解决两件事

**一、旋律不用开盲盒。** AI 生成歌曲，每按一次都是新的一次，出来的多半不是你脑子里那个调。这个工具反着来：旋律你亲手画，或者哼几句自动落格，当场听、当场改——确定下来的就是那一个版本，然后直接拿到带词简谱。

**二、作品归属清楚。** AI 一键生成的内容，著作权至今没有定论。这个工具里，你的每一份创作都可以**一键存证**：本地计算作品指纹（SHA-256 哈希），生成存证卡与创作说明，为著作权登记配上申报材料。材料在你自己的电脑上生成、留在你自己手里——作品的权属，就清楚在你这儿。

## 功能

- 🎵 **画格子 / 哼唱作曲**：格子上点一点，或哼唱几句自动落格成草稿，再逐音修改；断音笔、升降半音、八度扩展都支持——旋律立刻能听，不用懂乐理、不用会乐器（哼唱全程本地分析，录音不出你的电脑）
- 📖 **自动出带词简谱**：歌词整段粘贴，逐字落到音符上；符杠、附点、休止、八度点规范渲染，照着就能唱
- 🛡 **一键存证**：本地计算作品指纹（SHA-256）+ 哈希链 + OpenTimestamps 独立时间戳（比特币区块链）+ 手机验证码登录绑定身份，生成存证卡、创作说明等配套文件——为著作权登记配材料；登记机构的具体要求以其官网为准
- ⬇ **文件全带走**：带词乐谱 `.musicxml`（MuseScore / Sibelius / Dorico 可直接打开）、`.mid`（iPhone 库乐队 / FL / Cubase 可直接打开）、简谱图片 `.png`（带指纹水印，可作著作权登记的作品样本）——全部下载到你的电脑，打印、转发、交材料随你用
- 💾 **草稿随身带**：本地草稿箱常驻页面下方，复制式备份/导入；登录后云端同步，换设备不丢

## 技术特点

- **单个 HTML 文件**：无框架、无构建、无依赖，双击就能跑
- 音色全部 Web Audio 程序化合成：泛音独立衰减建模 + 击弦瞬态 + 微失谐增厚 + 生成式 IR 混响（弦乐为微失谐锯齿组 + 颤音渐入 + 低通扫频）
- MusicXML（divisions=120，跨小节自动 tie）与 MIDI（format 1 / division 480 / UTF-8 歌词事件）由前端直接生成，无服务器参与
- 所有数据（草稿、音色偏好）只存浏览器本地 localStorage，**不上传任何内容**

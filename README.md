# 画出原创乐曲（Draw Your Song）

把脑子里的一段旋律**画**出来，贴上歌词，当场听，然后带走一份「每个字都绑在音上」的乐谱——**轻松创作乐曲，并配上著作权申报文件**。

**不需要识谱，不需要会乐器，不需要安装任何东西。** 打开网页就能用：画音 → 贴词 → ▶ 播放 → 满意就导出。

**旋律和词都是你亲手做的，作品权利归你**——不用再琢磨「AI 生成的歌到底算不算我的」。

## 版权归你：这是它和 AI 生成音乐的根本区别

AI 一键生成的音乐，内容著作权至今没有定论——国内外都还在争，各家平台条款各说各话，想商用心里没底。

这个工具走的是相反的路：**旋律是你亲手一个音一个音画出来的，词是你自己的**，你的创作投入从画布上看得见。这是实打实的智力创作，作品权利归你，清清楚楚。工具本身只是笔和纸——纸上写出来的歌，归拿笔的人。

## 它解决什么问题

很多能哼出旋律的人，卡在这几件事上：

- 哼完就忘，存不下来
- 用 AI 生成歌曲，出来的总不是脑子里那个调
- 有词没曲、有曲没词，不知道怎么一一对应

这个工具不帮你"生成"，它帮把你**已有的**那段旋律**固定下来**：

- 横向每一格是 1/16 音符，纵向是三个八度的调内音
- 歌词整段粘贴，按时间顺序逐字落到音符上，画布上每个音上方直接显示它唱的字
- 满意后导出，词曲的对应关系**原封不动带走**

## 功能

- 🎨 **画布作曲**：按住拖动画音、再点一下擦除；断音笔切开长音唱两个字；右键升/降半音 ♯♭♮
- 🎙 **哼唱落格**：点录音键哼几句，音高检测自动吸附到格子成为草稿，再逐音修改（全程本地分析）
- 🔊 **三种音色可叠**（钢琴 / 弦乐 / 笛子），全部浏览器内程序化合成，零音频文件、零下载
- 📖 **真简谱渲染**：符杠、十六分双杠、附点、延长线、八度点、休止，歌词逐字对齐在所唱音的正下方
- 💾 **本地草稿箱**：常驻页面下方不弹窗；复制式备份/导入，跨设备搬草稿
- ⬇ **导出** `.musicxml`（带词乐谱，MuseScore / Sibelius / Dorico 可直接打开）、`.mid`（iPhone 库乐队 / FL / Cubase 可直接打开）与 **简谱图片 .png**（带指纹水印，可直接用作著作权登记的作品样本）
- 🛡 **作品存证**：本地计算作品指纹（SHA-256）+ 哈希链 + OpenTimestamps 独立时间锚定（比特币区块链）+ 手机验证码登录绑定身份——一键生成证据包，著作权登记的"作品样本 + 创作时间证据"一次备齐

## 技术特点

- **单个 HTML 文件**：无框架、无构建、无依赖，双击就能跑
- 音色全部 Web Audio 程序化合成：泛音独立衰减建模 + 击弦瞬态 + 微失谐增厚 + 生成式 IR 混响（弦乐为微失谐锯齿组 + 颤音渐入 + 低通扫频）
- MusicXML（divisions=120，跨小节自动 tie）与 MIDI（format 1 / division 480 / UTF-8 歌词事件）由前端直接生成，无服务器参与
- 所有数据（草稿、音色偏好）只存浏览器本地 localStorage，**不上传任何内容**
